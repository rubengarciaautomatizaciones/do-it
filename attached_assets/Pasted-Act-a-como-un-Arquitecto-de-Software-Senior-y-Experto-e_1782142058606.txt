PLAN DE EJECUCIÓN PASO A PASO:
Ejecuta esto en orden. No pases al siguiente paso sin terminar el anterior.
PASO 1: Configuración Base y PWA
Inicializa Next.js. Instala dependencias: @supabase/supabase-js, @supabase/ssr, lucide-react, next-pwa, framer-motion, @google/genai.
Configura next.config.mjs con next-pwa apuntando a public/sw.js.
Crea lib/supabase/client.ts y lib/supabase/server.ts para manejar la conexión.
PASO 2: Base de Datos (Supabase)
Crea un archivo supabase/schema.sql en la raíz con el código SQL para crear estas tablas y sus políticas RLS (Row Level Security) basadas en auth.uid():
tasks: id, user_id, titulo, descripcion, fecha_vencimiento, completada (boolean), created_at.
habits: id, user_id, nombre, frecuencia, created_at.
habit_logs: id, habit_id, fecha_completado.
(Nota para el agente: Solo genera el archivo SQL, el usuario lo ejecutará en Supabase).
PASO 3: Autenticación (Email/Contraseña)
Crea app/login/page.tsx. Diseño ultra limpio: Logo (icono.png), inputs de email y contraseña (bg-gray-50 rounded-lg), y un botón negro "Entrar / Registrarse".
Implementa la lógica de login/signup usando @supabase/ssr. Las sesiones deben ser persistentes.
Protege la ruta raíz (/) con un middleware (middleware.ts) que redirija a /login si no hay sesión.
Crea un app/layout.tsx que incluya la Bottom Tab Bar (solo visible si hay sesión).
PASO 4: Módulo de Tareas y UI Principal
Crea app/page.tsx (Listado de Tareas).
Componente de Tarea: Círculo a la izquierda (border-2 border-gray-300 rounded-full). Al hacer click, animación con framer-motion rellenándolo de negro y marcando la tarea como completada en Supabase.
Input Mágico (Bottom): Justo encima del Tab Bar, una pastilla rounded-full bg-gray-50. A la izquierda un input de texto, a la derecha un botón de micrófono.
PASO 5: Pipeline de Audio con IA (Gemini)
En el botón de micrófono, usa MediaRecorder API. Al mantener pulsado, graba audio. Al soltar, envía el blob (audio/webm o mp4) a /api/transcribe.
Crea app/api/transcribe/route.ts. Esta ruta debe:
Recibir el audio.
Enviar el audio a la API de Gemini 1.5 Flash (@google/genai).
Prompt para Gemini: "Extrae de este audio una tarea. Devuelve un JSON estricto con: 'titulo' (string corto), 'descripcion' (string o null), 'fecha_vencimiento' (ISO 8601 o null)".
Guardar el JSON devuelto en la tabla tasks de Supabase asociado al usuario autenticado.
Retornar éxito al frontend para actualizar la lista.
PASO 6: Habit Tracker
Crea app/habits/page.tsx.
Muestra la lista de hábitos.
Implementa lógica visual simple: cuadritos de los últimos 7 días por hábito. Si está completado, el cuadro es negro; si no, gris claro (bg-gray-100).
